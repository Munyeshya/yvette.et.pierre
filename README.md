# yvette.et.pierre

Wedding invitation website for D. Yvette and J.Pierre.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Vercel

This repository is configured for Vercel as a Vite project.

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

Connect the GitHub repository to Vercel and deploy. No environment variables are required.
